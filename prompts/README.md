# Prompts

Ready-made prompts for AI coding assistants (Claude Code, Cursor, Copilot and the like).
Open the repo in your assistant, copy the prompt for what you want to do, fill in the
parts in `<angle brackets>`, and paste it. Each one asks the assistant to follow the
project's rules (`AGENTS.md`), show you screenshots before and after, and explain the
change in plain words.

| I want to... | Prompt |
|---|---|
| change how something looks (wording, color, size, position) | [change-the-look.md](change-the-look.md) |
| add something new | [add-a-feature.md](add-a-feature.md) |
| fix something that's wrong | [fix-a-bug.md](fix-a-bug.md) |
| add a screenshot scenario so a change can be seen | [add-a-screenshot-scenario.md](add-a-screenshot-scenario.md) |
| check my change before I open a PR | [review-my-change.md](review-my-change.md) |
| open the pull request | [open-a-pull-request.md](open-a-pull-request.md) |

No assistant? The same steps work by hand: [CONTRIBUTING.md](../CONTRIBUTING.md).
