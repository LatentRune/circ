Type

Marcellus for headings

In game Circ uses the game's own fonts (GameFontNormal, GameFontHighlight and their sizes; ui/Window.lua:177-222), which are Friz Quadrata. It isn't free to use on the web, so the site uses Marcellus from Google Fonts, a flared capital face in the same spirit, for headings, and the reader's system font for text.

Art the addon uses

  • Coin: INV_Misc_Coin_02 on the minimap button (ui/Minimap.lua:28); the icon's coin comes from it.
  • Money: the gold, silver and copper icons (ui/widgets/MoneyInput.lua:9-11).
  • Panels: tooltip background and border (ui/Guide.lua:68-72, ui/widgets/Suggest.lua:42-45).
  • Window and buttons: the game's BasicFrameTemplateWithInset and UIPanelButtonTemplate (ui/Window.lua:163, ui/widgets/Toolbar.lua:8).
